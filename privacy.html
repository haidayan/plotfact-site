Privacy Policy

Last updated: September 9, 2026

YouTube API Services

PlotFact uses YouTube API Services and the YouTube Analytics API to manage the owner's PlotFact channel and retrieve aggregate performance metrics.

Use of YouTube features is also subject to the YouTube Terms of Service and Google Privacy Policy.

Data accessed and use

The workflow may access video identifiers, titles, descriptions, publication status, timestamps, aggregate statistics and analytics. This data is used only for PlotFact channel operations, human review before publication, performance measurement and internal content optimization.

Storage, retention and deletion

PlotFact limits stored API data to what is needed for channel operations and internal analytics, follows applicable YouTube API Services Developer Policies, and removes temporary upload files after processing.

Access revocation

The channel owner can revoke Google access at any time from Google Account permissions. Once revoked, the workflow cannot access YouTube API data until authorized again.
