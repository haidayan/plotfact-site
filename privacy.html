Privacy Policy

Last updated: September 10, 2026

YouTube API Services

PlotFact uses YouTube API Services and the YouTube Analytics API to manage the owner's PlotFact channel and retrieve aggregate performance metrics.

Use of YouTube features is also subject to the YouTube Terms of Service and Google Privacy Policy.

TikTok API Services

PlotFact uses TikTok Login Kit and the TikTok Content Posting API for the owner's PlotFact account. The integration requests basic profile access and permission to upload original PlotFact videos to TikTok as drafts/inbox items for the owner to review and complete in TikTok.

PlotFact does not use TikTok authorization to publish content publicly without an explicit human publication decision.

Data accessed and use

The workflow may access account identifiers, display name, video identifiers, titles, descriptions, publication status, timestamps, aggregate statistics and analytics where authorized. This data is used only for PlotFact account operations, human review before publication, performance measurement and internal content optimization.

Storage, retention and deletion

PlotFact limits stored API data to what is needed for account operations and internal analytics. OAuth credentials are stored server-side and are not exposed through the public website. Temporary upload files are removed after processing where supported by the workflow.

Access revocation

The account owner can revoke connected-platform access from the relevant platform account settings. Once revoked, the workflow cannot access that platform's API data until authorized again.
