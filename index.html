Platform integrations

YouTube is used for the owner's PlotFact channel workflow, including private QA uploads, human-approved publication and aggregate performance analysis.

TikTok integration uses Login Kit and the Content Posting API. The initial integration uploads original PlotFact media to the owner's TikTok inbox/draft flow. The owner reviews and completes publication in TikTok; public release is not automatic.

Public release remains an explicit human decision.
